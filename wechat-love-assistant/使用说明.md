# 💕 微信恋爱军师 - 快速使用版

## ✅ 已就绪！可以直接使用

### 🚀 启动方法

**双击运行:**
```
lightweight_app.bat
```

**或命令行:**
```bash
cd F:\dsh harness work\wechat-love-assistant
python lightweight_app.py
```

### 📋 使用步骤

#### 方式一：截图分析
1. 点击"截取聊天窗口"按钮
2. 程序会自动截图并保存
3. 点击"开始分析"
4. 复制生成的提示文本
5. 粘贴到 DSH 对话中
6. DSH 会调用"狗头军师"给出分析

#### 方式二：文字分析
1. 在微信中复制聊天记录
2. 选择"文字分析"模式
3. 点击"开始分析"
4. 粘贴聊天记录
5. 复制分析提示到 DSH

### 💡 提示
- 点击"置顶窗口"让窗口始终在最前面
- 点击"复制结果"快速复制分析提示
- 截图保存在 `screenshots/` 文件夹
