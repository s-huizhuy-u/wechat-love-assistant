## 📖 项目简介

**微信恋爱军师** 是一款零依赖桌面工具，帮助你把微信聊天记录转化为结构化的分析请求，交给 DeepSeek Harness（DSH）中的「狗头军师」技能，获得情绪承接、事实拆分和可直接发送的回复建议。

### 为什么需要这个工具？

DSH 的「狗头军师」技能分析聊天记录时，需要明确的 **说话人映射**（谁是你、谁是对方）和 **结构化输入**。手动整理既繁琐又容易出错——这个工具帮你自动完成：

1. **解析** → 自动识别微信/QQ 导出格式，清洗昵称
2. **映射** → 提取说话人，让你确认「我是谁 / 对象是谁」
3. **构造** → 按狗头军师框架生成结构化提示词
4. **交付** → 一键复制到剪贴板，切到 DSH 直接粘贴发送

## 🚀 快速开始

### 系统要求

- Python 3.8+（系统自带即可，无需 pip 安装）
- Windows / macOS / Linux（仅使用标准库）

### 三步上手

```bash
# 1. 打开程序（双击桌面图标或运行）
双击 "恋爱军师" 图标

# 2. 粘贴聊天记录
在微信里复制聊天记录 → 粘贴到程序

# 3. 确认映射并分析
选择「我是谁 / 对象是谁」→ Ctrl+Enter → 切到 DSH 粘贴发送
```

**全程无需安装任何依赖。**

## ✨ 核心特性

### 🎯 说话人映射确认

军师的分析质量取决于「谁说了哪句」。本程序强制你确认映射关系，绝不猜测：

- 自动识别记录中的昵称，下拉框选择
- 未确认时保留原始昵称，让军师先反问你
- 确认过一次后永久记住，下次自动带出

### 📱 智能格式解析

支持 4 种常见聊天记录排版，无需手动整理：

| 格式 | 示例 |
| --- | --- |
| 微信导出（昵称在前） | `张三 2024-05-01 20:30:15` 换行接内容 |
| QQ 导出（时间在前，带账号） | `2024-05-01 20:30:15 张三 (123456)` |
| 单行冒号 | `张三：今天好累啊` |
| 带方括号时间戳 | `[2024-05-01 20:30] 她：今天好累啊` |

**自动处理：**
- 昵称尾部账号自动清洗：`(123456)`、`<xxx@qq.com>`、`（wxid_abc）`
- 只在记录中反复出现的昵称才算说话人
- 「他说：……」这类句子不会被误判

### ⚡ 一键出提示

```
Ctrl+Enter → 自动复制提示 → 切 DSH → 粘贴 → 发送
```

提示词自动包含：
- 说话人映射（已确认）
- 聊天记录（已规范化）
- 补充背景（自动保存）
- 狗头军师分析框架要求

### 💾 智能记忆

| 功能 | 说明 |
| --- | --- |
| **补充背景** | 一次填写永久记住（如「认识两个月，她是 INTJ」） |
| **说话人映射** | 确认过一次后下次自动带出 |
| **历史记录** | 保留最近 30 次，可回看、重新载入 |

## 📖 详细用法

### 两种分析模式

| 模式 | 适用场景 | 输出内容 |
| --- | --- | --- |
| **完整分析** | 想全面了解关系状态 | 情绪落地 → 事实拆分 → 利益判断 → 明确建议 → 行动收束 |
| **只要一句回复** | 急着要一条能发的消息 | 直接给可复制成品 → 发送时机 → 代价 → 三种后续应对 |

### 说话人映射详解

**为什么必须确认？**

军师的分析质量取决于「谁说了哪句」。根据左右位置、语气或性别去猜，在长记录里很容易把两个人搞反，后面所有判断都会歪。

| 状态 | 行为 |
| --- | --- |
| **未确认** | 记录保留原始昵称，提示让军师先反问你「哪个昵称是你本人」 |
| **已确认** | 记录改写为「我 / 对方」，提示让军师沿用映射，不翻转 |
| **已保存** | 下次启动自动带出，不用重复选 |

### 补充背景

填写一次永久记住，不用每次重打：

```
例如：认识两个月了，她是 INTJ 类型，最近她回复消息变慢了...
```

## ❓ 常见问题

### Q：为什么非要我确认「我是谁」？
A：军师要靠「谁说了哪句」来判断关系。猜错了（比如按左右位置猜），后面所有建议都会跟着歪。确认过一次就记住，下次不用重复。

### Q：粘贴的记录很乱，要自己整理吗？
A：不用。微信/QQ 导出的排版、`张三：内容` 这种单行格式、带时间戳的、昵称后面跟着 `(123456)` 或邮箱的，都能自动认出来。

### Q：记录里的「他说：……」会不会被当成发言人？
A：不会。只有在记录里反复出现的昵称才算说话人。

### Q：聊天内容会被上传吗？
A：不会。程序不联网，内容只留在你本机的粘贴框和 `data/history.json` 里。不想留就删掉 `data` 文件夹。

### Q：支持 Mac / Linux 吗？
A：支持。程序只用 Python 标准库（tkinter），跨平台可用。
