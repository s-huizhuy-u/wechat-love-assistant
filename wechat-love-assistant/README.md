# 💕 微信恋爱军师

> 把微信聊天记录变成结构化分析请求，交给 DSH「狗头军师」技能，拿到情绪承接、事实拆分和可直接发送的回复。

[![Python](https://img.shields.io/badge/Python-3.8+-blue.svg)](https://www.python.org/)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

## 🚀 快速开始

```
微信复制聊天 → 粘贴到程序 → 确认说话人 → Ctrl+Enter → 自动复制 → 切 DSH 粘贴发送
```

**全程 5 步，无需安装任何依赖**（零依赖，仅用 Python 标准库）。

## ✨ 核心特性

| 特性 | 说明 |
| --- | --- |
| 🎯 **说话人映射确认** | 自动识别昵称，强制用户确认「我是谁 / 对象是谁」，绝不猜测 |
| 📱 **智能格式解析** | 微信/QQ 导出、单行冒号、带时间戳——4 种格式自动识别 |
| 🔒 **证据边界对齐** | 未确认映射时保留原始昵称，让军师先反问你，不瞎猜 |
| ⚡ **一键出提示** | Ctrl+Enter → 自动复制提示到剪贴板，切 DSH 直接粘贴 |
| 💾 **背景自动保存** | 补充背景（如「认识两个月，她是 INTJ」）一次填写永久记住 |
| 📚 **历史记录** | 最近 30 次分析，可回看、重新载入、再次复制 |
| 📊 **客观计数** | 附上双方消息条数供互惠判断，标注「仅原始条数，非结论」 |

## 📋 使用流程

```
┌─────────────────────────────────────────────────────────────┐
```

## 📖 详细用法

### 两种分析模式

| 模式 | 适用场景 | 输出内容 |
| --- | --- | --- |
| **完整分析** | 想全面了解关系状态 | 情绪落地 → 事实拆分 → 利益判断 → 明确建议 → 行动收束 |
| **只要一句回复** | 急着要一条能发的消息 | 直接给可复制成品 → 发送时机 → 代价 → 三种后续应对 |

### 说话人映射

**为什么必须确认？**

军师的分析质量取决于「谁说了哪句」。根据左右位置、语气或性别去猜，在长记录里很容易把两个人搞反，后面所有判断都会歪。

| 状态 | 行为 |
| --- | --- |
| **未确认** | 记录保留原始昵称，提示让军师先反问你「哪个昵称是你本人」 |
| **已确认** | 记录改写为「我 / 对方」，提示让军师沿用映射，不翻转 |
| **已保存** | 下次启动自动带出，不用重复选 |

### 支持的聊天记录格式

| 格式 | 示例 |
| --- | --- |
| 微信导出（昵称在前） | `张三 2024-05-01 20:30:15` 换行接内容 |
| QQ 导出（时间在前，带账号） | `2024-05-01 20:30:15 张三(123456)` |
| 单行冒号 | `张三：今天好累啊` |
| 带方括号时间戳 | `[2024-05-01 20:30] 她：今天好累啊` |

**自动处理：**
- 昵称尾部账号自动去掉：`(123456)`、`<xxx@qq.com>`、`（wxid_abc）`
- 只在记录里反复出现的昵称才算说话人
- 「他说：……」这类句子不会被误判成发言人

### 补充背景

填写一次永久记住，不用每次重打：

```
例如：认识两个月了，她是 INTJ 类型，最近她回复消息变慢了...
```

## ❓ 常见问题

### Q：为什么非要我确认「我是谁」？
A：军师要靠「谁说了哪句」来判断关系。猜错了（比如按左右位置猜），后面所有建议都会跟着歪。确认过一次就记住，下次不用重复。

### Q：粘贴的记录很乱，要自己整理吗？
A：不用。微信/QQ 导出的排版、`张三：内容` 这种单行格式、带时间戳的、昵称后面跟着 `(123456)` 或邮箱的，都能自动认出来。

### Q：记录里的「他说：……」会不会被当成发言人？
A：不会。只有在记录里反复出现的昵称才算说话人。

### Q：聊天内容会被上传吗？
A：不会。程序不联网，内容只留在你本机的粘贴框和 `data/history.json` 里。不想留就删掉 `data` 文件夹。

### Q：支持 Mac / Linux 吗？
A：支持。程序只用 Python 标准库（tkinter），跨平台可用。
