# 💕 微信恋爱军师（文字分析版）

把微信聊天记录变成一份结构化的分析请求，交给 DSH 里的 **狗头军师** 技能，
拿到情绪承接、事实拆分和可以直接发送的回复。

**零依赖**：只需要 Windows 自带的 Python 3（tkinter 是标准库），不用 pip 装任何东西。

## 快速开始

双击桌面的 **恋爱军师** 图标，或运行：

```bat
启动.bat
```

## 使用流程

```
1. 在微信里选中一段聊天记录，Ctrl+C 复制
2. 打开本程序，Ctrl+V 粘贴到「聊天记录」框
3. 选好「我是谁 / 对象是谁」，勾选「我已确认以上映射」
4. 按 Ctrl+Enter（或点「生成提示并复制」）
5. 切到 DSH 对话窗口，Ctrl+V，发送
```

提示会自动复制到剪贴板，第 4 步之后不用再点复制。

## 为什么一定要确认「说话人映射」

军师的分析质量取决于「谁说了哪句」。根据左右位置、语气或性别去猜，
在长记录里很容易把两个人搞反，后面所有判断都会歪。

所以本程序：

- 自动识别记录里的昵称，列成下拉框让你选
- **默认不做任何猜测**：没勾选确认时，生成的提示会保留原始昵称，
  并让军师先反问你一句「哪个昵称是你本人」
- 确认过一次后会记住（存在 `data/profile.json`），下次自动带出

## 支持的聊天记录格式

程序能自动解析这几种常见排版，不需要手动整理：

| 格式 | 例子 |
| --- | --- |
| 微信导出（昵称在前） | `张三 2024-05-01 20:30:15` 换行接内容 |
| QQ 导出（时间在前，带账号） | `2024-05-01 20:30:15 张三(123456)` |
| 单行冒号 | `张三：今天好累啊` |
| 带方括号时间戳 | `[2024-05-01 20:30] 她：今天好累啊` |

昵称尾部的 `(123456)`、`<xxx@qq.com>` 会自动去掉。
只在记录里反复出现的昵称才算说话人，所以「他说：……」这种句子不会被误判成发言人。

## 两种模式

- **完整分析**：按狗头军师的框架输出——情绪落地 / 事实拆分（已知·推测·未知）/
  利益判断 / 明确建议 / 行动收束，最后只追问 1-3 个关键问题。
- **只要一句回复**：第一屏先给一条可直接复制发送的成品，再补发送时机、
  主要代价，以及对方「积极 / 含糊 / 不回应」三种后续分别怎么接。

## 其它功能

- **补充背景**：填一次就会自动保存，不用每次重打（如「认识两个月，她是 INTJ」）
- **自动检测剪贴板**：勾上之后，复制聊天记录即自动生成提示
- **历史记录**：保留最近 30 次，可回看、重新载入、再次复制
- **客观计数**：提示里会附上双方消息条数，作为互惠判断的原始参考，
  并明确标注「仅原始条数，非结论」

## 文件说明

```
app.py            主程序（零依赖）
启动.bat          启动脚本
data/profile.json 自动保存的补充背景与已确认映射
data/history.json 最近 30 次分析历史
```

两个 `data` 文件都是纯文本 JSON，可以随时删掉，程序会重新生成。

## 隐私提示

聊天内容只存在于本机粘贴框和 `data/history.json` 里，程序不联网、不上传。
如果不想留存，直接删掉 `data` 文件夹即可。
