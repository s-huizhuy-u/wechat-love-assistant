# 💕 微信恋爱军师 - 桌面悬浮窗版

基于"狗头军师"技能打造的微信聊天辅助工具，提供实时恋爱建议和回复策略。

## ✨ 功能特性

- 📸 **截图分析** - 截取微信聊天截图，AI智能分析
- 📝 **文字分析** - 粘贴聊天记录，获取专业建议
- 🎯 **情绪落地** - 先理解你的感受，再给实用建议
- 💬 **回复生成** - 直接可复制的回复文案
- 📌 **悬浮窗口** - 始终置顶，随时查看
- ⚡ **快捷键** - 快速触发分析

## 🚀 快速开始

### 1. 安装依赖

```bash
cd wechat-love-assistant
pip install -r requirements.txt
```

### 2. 配置AI API

你需要配置一个支持多模态的AI API。推荐方案：

#### 方案A：使用DSH本地API (推荐)

```bash
# 设置环境变量
export OPENAI_API_URL="http://127.0.0.1:43129/v1"
export OPENAI_API_KEY="your-dsh-api-key"
export OPENAI_MODEL="qwen3.6-35b-a3b"
```

#### 方案B：使用本地模型 (Ollama)

```bash
# 安装Ollama并拉取模型
ollama pull qwen2.5:7b

# 启动Ollama API服务
# 默认运行在 http://localhost:11434

# 配置环境变量
export OPENAI_API_URL="http://localhost:11434/v1"
export OPENAI_API_KEY="ollama"
export OPENAI_MODEL="qwen2.5:7b"
```

#### 方案C：使用OpenAI兼容API

```bash
export OPENAI_API_URL="https://api.your-provider.com/v1"
export OPENAI_API_KEY="your-api-key"
export OPENAI_MODEL="your-model-name"
```

### 3. 运行程序

```bash
python main.py
```

## 📖 使用说明

### 截图分析模式

1. 在微信中查看聊天记录
2. 使用截图工具截取聊天区域
3. 点击"截图分析"按钮
4. 粘贴截图或选择图片文件
5. 查看AI分析结果和回复建议

### 文字分析模式

1. 复制微信聊天记录文字
2. 点击"文字分析"按钮
3. 程序自动从剪贴板读取
4. 可选：补充背景信息
5. 查看分析结果

### 补充背景信息

在"补充背景"框中输入额外信息，可获得更精准的建议：

```
例如：
- 我们认识两个月了
- 她是INTJ类型
- 最近回复消息变慢了
- 我们上次约会是一周前
```

## 🔧 配置说明

编辑 `config.py` 文件调整配置：

```python
# API配置
OPENAI_API_URL = "http://localhost:11434/v1"  # API地址
OPENAI_API_KEY = "ollama"                      # API密钥
OPENAI_MODEL = "qwen2.5:7b"                    # 模型名称

# 窗口配置
WINDOW_WIDTH = 400      # 窗口宽度
WINDOW_HEIGHT = 600     # 窗口高度
WINDOW_OPACITY = 0.95   # 窗口透明度
```

## 📋 分析输出格式

```
【情绪分析】
(2-4句情绪落地，理解你的感受)

【事实梳理】
- 已知：聊天记录中的明确信息
- 推测：基于行为的合理推断
- 未知：需要进一步确认的信息

【建议回复】
可直接复制的回复内容

【发送策略】
- 发送时机：何时发送最佳
- 可能回应及应对：不同回应的处理策略

【行动建议】
一个具体可执行的小动作
```

## 🆘 常见问题

### Q: 分析失败怎么办？

A: 检查：
- API是否配置正确
- 网络连接是否正常
- 模型是否支持多模态 (截图分析需要)

### Q: 如何更换模型？

A: 修改 `config.py` 中的 `OPENAI_MODEL` 变量，或设置环境变量 `OPENAI_MODEL`

### Q: 可以离线使用吗？

A: 使用本地模型 (如Ollama) 可以实现完全离线分析

### Q: 支持哪些聊天软件？

A: 理论上支持任何聊天软件，只要你能提供截图或文字
